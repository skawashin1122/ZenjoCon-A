データを扱う上で気づいた注意点

  1. 冊子によって集計期間がバラバラ：消防は暦年、人口動態は年度、保健衛生は12/31や10/1時点 → 調査時点で並べ直した。
  2. 同じ数値の使い回し：R7版とR8版の保健衛生（R5.10.1）は同じ数値。
  3. 矛盾するデータ：R5版の診療所数（R2.10.1・40）と R4版（R3.12.31・50）が合わない → 元の調査で確認が必要。
  4. 推計値と確定値の混在：R8版の地区別人口は推計値、R7国勢調査は速報値。
