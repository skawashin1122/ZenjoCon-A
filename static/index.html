にちなん・まもりネット

毎朝の「げんき」1タップが、もしもの日の命綱になる。

平常時の見守りが、そのまま救急・災害時の備えになる「フェーズフリー見守り」です。日南市の一人暮らし・高齢夫婦のみの世帯と、離れて暮らす家族のためのサービスです。

🌞 げんきボタンLINEで毎朝1回押すだけ。決めた時刻までに押されないと、家族にお知らせします。
📄 もしもカード →持病・薬の保管場所・家族の連絡先を大きな文字で印刷。冷蔵庫と非常袋へ。
📳 地震の安否確認日南市で震度5弱以上のとき、自動で「無事？」を送り、家族に結果を知らせます。
📊 データで見る日南 →人口は減ったのに救急出動は1人あたり約1.3倍。ミニ統計5年分のグラフ。

迷ったら

🔴 意識がない・息が苦しい・胸が痛い → 119番

🟡 救急車を呼ぶか迷う・夜間や休日 → 日南市救急医療電話相談
0987-31-1111（24時間365日・医師・看護師が答えます）

⚪ 自分で調べたい → 全国版救急受診アプリ「Q助」（消防庁）

※このサービスは医療の判断をしません。迷ったら119番へ。

始め方

  1. LINEで「にちなん・まもりネット」を友だち追加する
  2. 利用のきまりを読み、「見守られる人（本人）」を選ぶ
  3. 表示された招待コード（6けた）を家族に伝える
  4. 家族も友だち追加して「家族」を選び、招待コードを送る

大切にしていること

  • 健康情報を預かりません。もしもカードはスマホの中だけで作って印刷します。
  • AIに命の判断をさせません。症状の判定は119番・市の電話相談・Q助に任せます。
  • 見張りません。毎日の記録は家族に送らず、押されなかった日だけお知らせします。
